# Bengaluru Fort visitor guide

Kannada and English visitor pages retain static Astro output and local photographs. The custom Worker consolidates the site origins, serves true error pages, and validates the fixed-site Open-Meteo forecast before a ten-minute cache. The existing analytics settings support verified saved choices and immediate withdrawal.

Build and verification commands are documented in README.md. Actual hosting and visitor access remain subject to the deployed version and monument notices.
